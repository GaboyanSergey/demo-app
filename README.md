# Demo App - Полный CI/CD цикл

## Об устройстве репозитория
- `main.go`, `go.mod` — исходный код приложения на Go.
- `Dockerfile` — инструкция для сборки Docker-образа.
- `helm/` — Helm-чарт для развертывания приложения в Kubernetes.
- `.github/workflows/` — пайплайны CI/CD.

## Развертывание инфраструктуры
Инфраструктура описана с помощью Terraform в отдельном репозитории (или папке `infra`).
1. Настройте доступ к Yandex Cloud (`yc init`).
2. Перейдите в папку `terraform` и выполните `terraform init` и `terraform apply`.
3. Кластер K3s развернется автоматически на виртуальной машине.
